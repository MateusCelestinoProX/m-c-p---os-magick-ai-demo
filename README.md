## 📌 Visão Geral da Demonstração

Esta versão **Demo** do **MAGICK A.I** foi estruturada especificamente para exibição profissional em portfólio de engenharia de software de alto nível. O sistema inicia com uma **Tela Base de Apresentação suave e cinematográfica**, transicionando através de um ciclo fluido de animações GSAP (*stagger, motion blur, drop-in* de cabeçalho e iluminação neon) diretamente para a interface completa do aplicativo.

> [!NOTE]
> **Arquitetura Multiplataforma**: O projeto foi desenvolvido sob arquitetura híbrida de alto desempenho: funciona como uma **Single Page Application (SPA) Web ultra-rápida e offline-first** e, simultaneamente, está configurado e pronto para compilação nativa no ecossistema **Android via Capacitor 8**, com mapeamento de botões de hardware e controle de ciclo de vida.

## ⚡ Módulos & Recursos em Destaque

### 1. 🔮 Grimório Sagrado dos 44 Servidores & Diabos
- **Catálogo Interativo Completo:** 40 Servidores de Tommie Kelly + os 4 Diabos oficiais (*Jerdehl*, *Harven*, *Vharmon* e *Kranvoc*).
- **Mapeamento Oracular & Operacional:** Cada entidade traz sua respectiva arte HD, sigilo isolado PNG com transparência, interpretação completa para Divinação e diretrizes para Magia Prática (Evocação e Banimento).
- **Filtros e Busca em Tempo Real:** Filtragem instantânea por categoria e pesquisa indexada sem latência.

### 2. ⚡ Energizador de Sigilos (Gnose & Transe)
- **Purificação Automática de Imagens:** Pipeline em Canvas que processa e purifica uploads de sigilos manuais (removendo automaticamente folhas brancas de papel ou fundos pretos para que apenas o glifo emane luz no altar).
- **Paleta de 12 Cores de Emissão:** Ajuste dinâmico de matiz, brilho e luminescência do sigilo no palco.
- **6 Shaders WebGL Interativos (React Bits):** *Balatro Shader, Ferrofluid, MetaBalls, Plasma, SplashCursor e PrismaticBurst*.
- **9 Portais Hipnóticos Integrados:** Alternância entre shaders de alta intensidade e vídeos geométricos em loop contínuo.

### 3. 🃏 Cyberdivinação Oracular 3D
- **Física 3D com GSAP:** Ciclo de 5 fases rituais:
  1. *Distribuição Inicial 3D:* 40 cartas posicionadas em matriz com face revelada.
  2. *Ocultação em Massa:* Flip simultâneo e suave das faces.
  3. *Embaralhamento Caótico 3D:* Rodadas sequenciais em que cartas convergem ao centro gravitacional, sofrem rotação caótica e são redisparadas para o tabuleiro.
  4. *Seleção Tátil Interativa:* Hover com elevação de camada e rotação tridimensional.
  5. *Revelação Oracular:* Modal glassmorphic com leitura interpretativa imediata.
- **Síntese Sonora Web Audio API:** Frequência harmônica de 528Hz sintetizada em tempo real via osciladores senoidais durante a abertura do ritual e transições.

### 4. 🎨 Motor de Fundo Cinematográfico Dinâmico
- **59 Imagens HD em 4 Categorias Temáticas:** `caosphere`, `celestial`, `horror` e `satanic`.
- **Slideshow com Interpolação Cruzada:** Troca suave a cada 3 segundos com controles em tempo real de opacidade (*Dim Overlay* 0% a 90%) e desfoque (*Gaussian Blur* 0px a 20px).

## 🚀 Como Executar a Demonstração

### Opção A: Executar Diretamente no Navegador (Web SPA)
Como todos os bundles de scripts e estilos são offline-first e residem em `assets/`, a demonstração pode ser executada abrindo o arquivo `index.html` ou servindo localmente:

```bash
# Via Bun
bun run build

# Ou usando qualquer servidor HTTP simples
npx serve dist
```

### Opção B: Compilação do App Nativo Android
```bash
# 1. Sincronizar os assets web com o projeto Android
bun run android:sync

# 2. Compilar APK de depuração (Debug Build)
cd android && ./gradlew assembleDebug
```
